# Dreamcast Automator

Визуальный нодовый автоматизатор Minecraft 26.2 на базе Baritone и Fabric.

![Minecraft 26.2](https://img.shields.io/badge/Minecraft-26.2-62B47A) ![Fabric](https://img.shields.io/badge/Loader-Fabric-DB3A24) ![Java 25](https://img.shields.io/badge/Java-25-ED8B00) ![Build](https://github.com/inkvizrebirth/Dreamcast/actions/workflows/build.yml/badge.svg) ![CC0-1.0](https://img.shields.io/badge/License-CC0--1.0-lightgrey)

## Возможности

- Нодовый визуальный конструктор с направленными связями
- Интеграция с Baritone для навигации, добычи и взаимодействия
- Визуальный редактор регионов через FreeCam
- Глобальные переменные-маркеры с сохранением координат
- Режим «Легит» с античит-маршрутизацией
- Пользовательские переменные и условия
- Конфиги сценариев в JSON
- Автоматическая сборка через GitHub Actions

## Сборка

```bash
JAVA_HOME=/path/to/jdk-25 ./gradlew build
```
