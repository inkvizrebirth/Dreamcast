# Dreamcast Automator

Визуальный автоматизатор Minecraft 26.2 на базе Fabric и Baritone. Вместо набора
чит-модулей клиент предоставляет конструктор сценариев: действия размещаются на
поле, соединяются линиями, получают параметры и выполняются как единый workflow.

## Возможности

- несколько сохраняемых конфигов;
- перетаскиваемые узлы и направленные связи;
- встроенный Baritone 26.2 из ветки MeteorDevelopment;
- переход к координатам, поиск блоков и добыча через Baritone;
- открытие блоков, использование предметов, следование за сущностью;
- перенос, shift-клик и выбрасывание предметов, сбор открытого контейнера;
- выбор хотбар-слота и автоматическое поедание выбранного типа еды;
- проверки голода, здоровья и количества предметов с ветками «Да» / «Нет»;
- плавный взгляд, ручное движение, приседание, прыжок, атака и взаимодействие;
- исследование мира, фарм и отправка сообщений;
- проверка координат с отдельными выходами «Да» / «Нет»;
- произвольные команды Baritone;
- ожидание, переменные и условия с выходами «Да» / «Нет»;
- режим «Легит»: anti-cheat-маршрутизация, отключение спринта/паркура,
  естественные повороты и плавное наведение перед взаимодействием;
- подстановка `${player.x}`, `${player.y}`, `${player.z}`, `${player.health}`,
  `${player.food}`, `${player.yaw}`, `${player.pitch}`, `${player.item}`,
  `${player.armor}`, `${player.air}`, `${player.slot}`, `${player.on_ground}`,
  `${player.sneaking}`, `${world.time}`, `${inventory.minecraft:bread}` и
  пользовательских переменных `${имя}`;
- запуск и остановка из библиотеки или редактора;
- ровный интерфейс на Manrope без пиксельной стилизации.

Конструктор открывается клавишей `Right Shift` или пунктом «Автоматизатор» в
главном меню. Конфиги сохраняются в `config/dreamcast/automations.json`.

## Как собрать сценарий

1. Нажмите «Добавить конфиг».
2. Выберите действие в левой панели.
3. Перетащите карточки и соедините цветной выход одного узла с серым входом другого.
4. Выберите узел и заполните параметры справа.
5. Для ветвления добавьте «Условие» и подключите оба выхода — «Да» и «Нет».
6. Сохраните и нажмите «Запуск».

Индексы в действиях инвентаря — это номера слотов текущего открытого меню.
Например, узел «Забрать из контейнера» последовательно выполняет обычные
shift-клики с заданной паузой, поэтому сервер видит те же операции, что и при
ручном управлении.

Поддерживаемые операторы условий: `==`, `!=`, `>`, `>=`, `<`, `<=`, `contains`.

## Установка и сборка

Нужны Minecraft 26.2, Fabric Loader 0.19+ и Fabric API. Baritone отдельно
устанавливать не нужно: Loom вкладывает совместимую сборку в итоговый JAR.
Сборка требует Java 25:

```bash
JAVA_HOME=/path/to/jdk-25 ./gradlew build
```
