# Dreamcast Automator

Визуальный нодовый автоматизатор Minecraft 26.2 на базе Baritone и Fabric.

![Minecraft 26.2](https://img.shields.io/badge/Minecraft-26.2-62B47A) ![Fabric](https://img.shields.io/badge/Loader-Fabric-DB3A24) ![Java 25](https://img.shields.io/badge/Java-25-ED8B00) ![Build](https://github.com/inkvizrebirth/Dreamcast/actions/workflows/build.yml/badge.svg) ![CC0-1.0](https://img.shields.io/badge/License-CC0--1.0-lightgrey)

## Установка

1. Установите Fabric Loader для Minecraft 26.2, Fabric API и Baritone.
2. Скопируйте собранный `dreamcast-*.jar` в `.minecraft/mods`.
3. Запустите клиент. Меню Dreamcast открывается клавишей `Right Shift`.

## Библиотека конфигов

На стартовом экране слева находятся два раздела:

- **Профили Baritone** — встроенные `AutoWalk`, `AutoMine`, `AutoFarm`.
- **Мои конфиги** — ваши сценарии из `config/dreamcast/automations.json`.

Встроенный профиль можно сразу запустить или скопировать в редактор. Свой конфиг создаётся через **Новый конфиг**. Правой кнопкой по пользовательскому конфигу открываются настройки режима «Легит».

## Нодовый редактор

1. Нажмите **Редактор** у своего конфига.
2. Добавьте ноды из левой панели и соедините порты справа налево.
3. Нажмите на ноду и измените параметры в инспекторе справа.
4. Нода **Таймер** ждёт указанное число секунд (стандартно 5). **Ожидание** оставлено для коротких пауз.
5. Ноды **Сообщение**, **Отправить в чат**, **Команда чата**, **Ждать чат** и **Проверка чата** позволяют строить сценарии с чатом.
6. Нажмите **Сохранить**, затем **Запуск**.

## Координаты и метки

В редакторе включите `FreeCam` или нажмите `F7`. Камера смотрит вниз, `WASD` перемещают её, а слайдер слева меняет высоту.

Для свободного обзора вокруг неподвижного игрока нажмите `F8` (`FreeLook`). Мышь вращает орбиту, Baritone продолжает работать с реальной сущностью игрока.

Для углов региона включите **+ блок** и нажимайте ЛКМ. Для глобальной метки включите **+ метка** и нажмите ПКМ по блоку, затем введите имя. Метки сохраняются в `config/dreamcast/regions.json`.

В ноде **Идти** параметр **Идти к** переключается между ручными координатами и меткой. В режиме метки список всегда содержит **+ Добавить метку**: выбор включает FreeCam, после установки метка сразу появляется в списке.

## Движение и паркур

Для обычного движения используйте ноду **Двигаться**. Для маршрута к точке — **Идти**; там отдельно настраиваются спринт, прыжок и прямой/кривой маршрут.

В ноде движения включите **Паркур Baritone** и выберите профиль:

- `Сбалансированный` — безопасные стандартные переходы;
- `Универсальный adaptive` — тик-контроллер анализирует препятствие, разрыв, высоту и положение относительно сегмента, затем выбирает момент прыжка и корректирует траекторию;
- `H2H Neo / 45°` — тот же адаптивный контроллер с фазовым 45°-доворотом для head-to-head Neo (прыжок между элементами, закрывающими голову).

Baritone по-прежнему строит маршрут, а Dreamcast корректирует только исполнение текущего паркурного сегмента. Ни один профиль не отменяет геометрию мира, пинг, серверный тик и античит: если на сервере нет физического окна для прыжка, мод не будет выдавать это за гарантированный успех.
