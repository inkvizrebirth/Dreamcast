# Dreamcast Automator

Визуальный автоматизатор для Minecraft 26.2 на Fabric и Baritone. Вместо
набора чит-модулей — конструктор сценариев: действия размещаются на поле,
соединяются направленными связями, получают параметры и выполняются как
единый workflow поверх встроенного Baritone.

Конструктор открывается клавишей `Right Shift` или пунктом «Автоматизатор» в
главном меню. Конфиги хранятся в `config/dreamcast/automations.json` и
переживают перезапуск клиента.

## Возможности

- Несколько независимых сохраняемых конфигов, запуск и остановка из
  библиотеки или прямо из редактора.
- Узлы перетаскиваются по полю и соединяются цветными выходами; ветвящиеся
  узлы дают отдельные выходы «Да» / «Нет».
- Переменные, условия (`==`, `!=`, `>`, `>=`, `<`, `<=`, `contains`) и
  ожидание — сценарий можно строить с реальной логикой, а не линейным
  списком шагов.
- Подстановки в любом текстовом поле: `${player.x}`, `${player.y}`,
  `${player.z}`, `${player.health}`, `${player.food}`, `${player.yaw}`,
  `${player.pitch}`, `${player.item}`, `${player.armor}`, `${player.air}`,
  `${player.slot}`, `${player.on_ground}`, `${player.sneaking}`,
  `${world.time}`, `${inventory.minecraft:bread}`, `${nearest_player.name}`,
  `${nearest_player.distance}` и произвольные пользовательские `${имя}`,
  заданные узлом «Переменная».
- Режим «Легит»: анти-чит-совместимая маршрутизация Baritone (`antiCheatCompatibility`,
  `randomLooking`, `overshootTraverse`) — про то, *как* бот перемещается и
  прокладывает путь, а не про запрет спринта или прыжков: те остаются
  обычным поведением игрока и включаются/выключаются отдельно (см. ниже).
  Правый клик по конфигу в библиотеке открывает быстрый переключатель
  «Легитная ротация», не заходя в редактор.
- Повороты камеры («Посмотреть», «Открыть») всегда линейные, тик за тиком,
  никогда не телепортируются мгновенно на угол — независимо от «Легит».
- Встроенный Baritone 26.2 (ветка MeteorDevelopment) — отдельно ставить
  не нужно, Loom вкладывает совместимую сборку в готовый JAR.
- Фирменная оболочка вокруг ванильного интерфейса: главное меню, списки
  миров и серверов, настройки и аккаунты — в едином тёмном стиле на
  шрифте Manrope, без пиксельной стилизации.
- Весь интерфейс конструктора — панели и абсолютно все кнопки — со
  стеклянным эффектом: тонкая световая кромка сверху и медленный блик,
  проходящий по поверхности.
- У узла «Идти» — два выпадающих списка вместо текстовых полей: «Спринт» /
  «Прыгать» (можно отметить любое количество, включая ноль) и маршрут
  «Прямой» / «Кривой» (прямой — кратчайший путь по прямой, кривой — один
  заметный обходной крюк примерно на середине пути вместо робота-по-линии,
  но всё ещё рассчитанный дойти быстро).
- Поиск по палитре действий, привязка узлов к сетке при перетаскивании и
  кнопка «Дублировать» для узла с параметрами — конструктор не заставляет
  собирать сценарий заново, если нужно повторить уже настроенный шаг.
- Кнопка «Добавить» в редакторе открывает второй, быстрый способ добавить
  узел: список действий по категориям (Движение, Инвентарь, Условия,
  Управление, Прочее) со своим поиском — не отменяет обычную палитру слева,
  просто быстрее для тех, кто знает, что ищет.
- «+ Добавить конфиг» сначала спрашивает, что делать: открыть конструктор
  или записать реальные действия. «Записать действия» закрывает интерфейс и
  пишет удержание WASD/прыжка/приседания и направление взгляда, тик за
  тиком, пока играете как обычно; `F6` (настраивается) останавливает запись
  и сохраняет её как новый конфиг с одним узлом «Воспроизведение записи».
  Это буквально повтор нажатых клавиш и поворотов камеры, а не телепорт по
  координатам — но функциональность пока не проверена вживую: опробуйте
  повтор в одиночной игре, прежде чем полагаться на неё на реальном
  сервере. Пока запись идёт, сверху экрана — стеклянная полоска со
  счётчиком кадров и подсказкой клавиши остановки (сама полоска не
  кликабельна — это просто HUD, останавливать нужно клавишей).
- Параллельные ветки: узел «Параллельный поток» запускает независимую ветку
  рядом с текущей (выход «Ветка» — новая ветка, «Далее» — продолжение
  текущей) — можно строить основную задачу и отдельно, одновременно с ней,
  зациклённую проверку чего-то ещё.
- Флаги для связи между ветками: «Установить флаг» поднимает именованный
  флаг, «Ожидание флага» блокирует ветку, пока где-то ещё (в том числе в
  параллельной ветке) не будет поднят флаг с тем же именем. Флаги общие на
  весь запущенный конфиг и не сбрасываются сами — если нужен одноразовый
  триггер, поднимайте новый флаг с уникальным именем на каждый цикл.

### Действия конструктора

| Категория | Узлы |
| --- | --- |
| Навигация (Baritone) | Идти, Добывать, Искать, Открыть, Следовать, Исследовать, Фармить, Команда |
| Инвентарь | Выбрать слот, Использовать, Переместить предмет, Быстро переместить, Выбросить предмет, Забрать из контейнера, Поесть |
| Проверки и ветвление | Условие, Проверка координат, Проверка голода, Проверка здоровья, Проверка предмета, Проверка контейнера, Проверка игроков |
| Управление персонажем | Посмотреть, Двигаться, Прыгнуть, Красться, Ударить, Взаимодействовать |
| Прочее | Сообщение, Ожидание, Переменная, Старт, Стоп, Параллельный поток, Установить флаг, Ожидание флага, Воспроизведение записи |

Полное описание каждого узла — прямо в редакторе, во всплывающей подсказке
палитры действий.

## Как собрать сценарий

1. Нажмите «Добавить конфиг».
2. Выберите действие в левой панели и перетащите его на поле.
3. Соедините цветной выход одного узла с серым входом другого.
4. Выберите узел и заполните параметры справа.
5. Для ветвления добавьте «Условие» (или любую проверку) и подключите оба
   выхода — «Да» и «Нет».
6. Сохраните конфиг и нажмите «Запуск».

Индексы в узлах, работающих с инвентарём, — это номера слотов *текущего
открытого* меню (хотбар, инвентарь или контейнер), а не абсолютные слоты
инвентаря. Например, «Забрать из контейнера» выполняет обычные shift-клики
с заданной паузой между ними — сервер видит те же пакеты, что и при ручной
игре.

## Установка и сборка

Нужны Minecraft 26.2, Fabric Loader 0.19+, Fabric API и Java 25 для сборки:

```bash
JAVA_HOME=/path/to/jdk-25 ./gradlew build
```

Готовый JAR — в `build/libs/`.
